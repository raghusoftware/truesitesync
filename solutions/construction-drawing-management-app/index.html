Drawing register format

A drawing register is the master list of every sheet on the project and its current revision. Keep one per project:

Status values: Tender → For approval → GFC → Superseded → As-built. Only GFC sheets go to the site.

A revision naming rule that works on site

[Discipline]-[Sheet no.]_R[Rev]_[Status]_[DD-MM-YY].pdf
Example: S-201_R3_GFC_14-10-26.pdf

The revision number goes in the file name, not just the title block. A supervisor can then see it on a phone without zooming into the PDF.

Six steps to keep every site on the latest drawing

1. One folder per project

Use subfolders for Architecture, Structure, MEP and Superseded. Never keep drawings in personal chats or email.

2. Log every sheet

Add it to the register before anyone gets a copy.

3. Supersede the same day

Move the old file to Superseded and collect the old print from site.

4. Tell the people who build it

Send a one-line note naming the sheet, the revision and what changed, to the engineer and the subcontractor.

5. Record the change against the work

When a revision changes work already done, log it as a change with its quantity impact. That's your claim for extra work.

6. Check weekly

Compare the register with the prints and files in use on site.

Frequently asked questions

What is a drawing register in construction?

A master list of every drawing on a project with its number, title, discipline, current revision, revision date, status and who it was issued to. It is how you prove which drawing was current on any date.

What does GFC drawing mean?

GFC means Good for Construction: the drawing has been approved for execution. Tender drawings and drawings issued for approval should not be used to build.

How do you control drawing revisions on site?

Use one shared folder, a revision number in every file name, a drawing register, and a Superseded folder for replaced sheets. Collect old prints the day a new revision is issued.

What is a superseded drawing?

A drawing replaced by a newer revision. Keep it as a record, but nobody should build from it.

Can I manage construction drawings on a mobile app?

Yes. Keep drawings in a shared project folder that syncs to every phone, so site engineers always open the same latest set. True Site Sync has a project documents area for this.

Who pays for rework caused by a revised drawing?

If the client or designer revised a GFC drawing after the work was built, the rework is usually a variation. Record the revision date and the quantities affected so you can claim it under your contract.
