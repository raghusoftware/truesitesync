# PDF fonts (Modern Design measurement / abstract sheets, Tax Invoice designs)

Loaded on demand by `js/modules/pdfModernTheme.js` and embedded into the PDF.

| File | Stands in for | Licence |
|------|---------------|---------|
| `URWGothic-Book.ttf`, `URWGothic-Demi.ttf` | Century Gothic (regular / bold) | AGPL-3.0 with font-embedding exception — unmodified from ArtifexSoftware/urw-base35-fonts; see `URWGothic-LICENSE.txt`, `URWGothic-COPYING.txt` |
| `TSSDocSans-Regular.ttf`, `TSSDocSans-Bold.ttf` | Calibri / Segoe UI (metric-compatible) | SIL OFL 1.1 — Latin + ₹ subset of Carlito, renamed per OFL; see `TSSDocSans-OFL.txt` |
| `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf`, `NotoSans-Black.ttf` | Segoe UI (Tax Invoice designs) | SIL OFL 1.1 — Latin + ₹ subset of Noto Sans (no Reserved Font Name); see `NotoSans-OFL.txt` |
