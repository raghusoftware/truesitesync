# True Site Sync — Demo Video Scripts (for the /solutions pages)

8 short screen-recording scripts, one per solution page. Each is ~60–75 seconds.
Drop the finished YouTube video ID into the `.video` block on the matching page
(the one-line `<iframe>` snippet is already in an HTML comment there).

## How to film (read once)
- **Tool:** OBS / QuickTime screen record on desktop, or the phone screen recorder for the mobile/offline shots.
- **Resolution:** 1920×1080, landscape. Record the app at a comfortable zoom so text is readable.
- **Length:** keep every video **under 90 seconds**. Shorter is better — aim 60–75s.
- **Prep a demo project first:** one project ("Riverside Tower"), a client, an imported BOQ with 8–10 items, a few measurements, and 2–3 RA bills already raised. Use realistic but non-real client data.
- **Audio:** a calm voiceover is ideal, but a silent screen recording with on-screen captions works too. No background music needed.
- **Captions:** burn in the key line of each step — most people watch muted.
- **End card (last 3s, every video):** logo + "truesitesync.com · Free 7-day trial".
- Format below: **[SCREEN: what you do]** — "Voiceover / caption line".
