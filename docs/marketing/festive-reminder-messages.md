# Festive reminder messages (Hinglish, PW Talk style)

Short, friendly reminders for people who signed up for a trial or viewed pricing
but haven't bought yet. Tone: casual Hinglish, a little FOMO, one clear CTA.

> **Before sending:** Only quote discounts that are actually live on
> `pricing.html` / `payment.html`. Prices below are the current list prices
> (Solo ₹2,400/yr ≈ ₹200/month, Starter ₹5,100/yr ≈ ₹425/month).
> Replace `{{...}}` placeholders. Get opt-in for WhatsApp/SMS (TRAI DLT
> template registration is required for promotional SMS in India).

## Style rules borrowed from the PW Talk message

1. **Empathetic opener:** "Din bhar busy the? Koi baat nahi" (no guilt-tripping).
2. **Personal hook:** "Offer aapka wait kar raha hai 👀"
3. **Bold price, per-month framing:** a small monthly number feels cheaper than a yearly one.
4. **One urgency line:** "Itna accha price baar baar nahi aata". Only use it when the offer really ends.
5. **Short CTA:** "Socho mat, shuru kar do" + one link.
6. **Sign off as a team:** "Team TrueSiteSync".
